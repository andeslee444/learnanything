### Task 1: Stripe foundation (ledger integration + webhook)

**Files:** migration (`billing_customers` + `stripe_ref` partial unique), `src/lib/stripe.ts`, `src/lib/credits.ts` (subscription grant fn), `src/app/api/billing/{checkout,portal,webhook}/route.ts`, .env.example, tests

- `npm i stripe` (official SDK — needed for webhook signature verification; lazy-init client ONLY when `STRIPE_SECRET_KEY` is set; module must import cleanly without it).
- Migration (drizzle-kit): `billing_customers` — id, userId text UNIQUE FK→user cascade, stripeCustomerId text UNIQUE, subscriptionStatus text NOT NULL default 'none' ('none'|'active'|'canceled'), currentPeriodEnd timestamptz nullable, createdAt/updatedAt. ALSO: partial unique index on `credit_ledger.stripe_ref` WHERE stripe_ref IS NOT NULL (webhook idempotency backstop).
- `src/lib/stripe.ts`: `getStripe()` → Stripe instance or null (no key); `SUBSCRIPTION_MONTHLY_CREDITS = 30` (one lesson = 1 credit; $15/mo ≈ 50¢/lesson — comment the founder can retune); typed `BillingUnavailableError`.
- `credits.ts`: `grantSubscriptionCredits(db, userId, stripeRef)` — advisory lock (domain 1, same as ensureMonthlyGrant), INSERT `{type:'purchase', amount: SUBSCRIPTION_MONTHLY_CREDITS, stripeRef}` with `onConflictDoNothing` on the stripe_ref index + returning() — returns {granted: boolean} (false = duplicate webhook delivery). Mirror ensureMonthlyGrant's structure.
- POST `/api/billing/checkout`: session auth (ladder root only — no learner needed); 503 BillingUnavailable when no key; create Checkout Session `{mode:'subscription', line_items:[{price: STRIPE_PRICE_ID, quantity:1}], client_reference_id: userId, success_url: APP_URL + '/billing?success=1', cancel_url: APP_URL + '/billing'}` → `{url}`. Upsert billing_customers row after session create only if customer known (else webhook fills it).
- POST `/api/billing/portal`: session auth; look up stripeCustomerId (404 if none); create billing-portal session → `{url}`.
- POST `/api/billing/webhook`: RAW body (`await req.text()` — Next App Router gives raw text; do NOT json() first) + `stripe.webhooks.constructEvent(raw, sig, STRIPE_WEBHOOK_SECRET)` (400 on bad signature; 503 when env unset). Handle: `checkout.session.completed` (resolve userId from client_reference_id; upsert billing_customers {stripeCustomerId, subscriptionStatus:'active'}; grant via grantSubscriptionCredits(stripeRef = event.id)); `invoice.paid` (resolve user via stripeCustomerId; grant w/ stripeRef = event.id — covers renewals; unknown customer → 200 + alertFounder('billing',{eventType}) content-free); `customer.subscription.deleted` (status 'canceled', keep remaining credits). Unhandled types → 200. Extract `handleStripeEvent(db, event)` exported for tests (route keeps raw-body + signature).
- alerts.ts: add `'billing'` to the alertFounder kind union.
- Env (.env.example, comments, no values): `STRIPE_SECRET_KEY=`, `STRIPE_WEBHOOK_SECRET=`, `STRIPE_PRICE_ID=`, `APP_URL=` (default http://localhost:3000 in code).
- Tests (REAL code paths — no tautologies): grantSubscriptionCredits idempotency (same stripeRef twice → one row, second returns granted:false — assert via DB read); handleStripeEvent for all 4 event shapes against the test DB (construct minimal event objects as plain JSON — no Stripe network); signature verification via `stripe.webhooks.generateTestHeaderString({payload, secret})` with a dummy secret → constructEvent round-trip in the route (one test through the actual POST export with a NextRequest); bad signature → 400; no STRIPE_SECRET_KEY → checkout route 503 and module imports cleanly; balance() reflects the grant.
